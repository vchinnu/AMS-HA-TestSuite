Execution Options (how the tool connects to your cluster VMs)

VM Run Command — Executes commands on cluster VMs via Azure API (no direct SSH needed). Requires the VMs to have the Azure VM Agent running. Best for most scenarios.
Azure Bastion SSH — Connects to VMs via an existing Azure Bastion host using SSH tunneling. Use this if VM Run Command is blocked by policy or the VM agent is unavailable.
Both (fallback) — Tries VM Run Command first; if it fails, automatically falls back to Bastion SSH. Recommended if you're unsure which method works in your environment.
